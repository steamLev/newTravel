# Regex для поиска partyIds с числами

## Формат: "partyIds":[111,111,222,33333]

### Основной regex:
```regex
"partyIds"\s*:\s*\[([^\]]+)\]
```

### Объяснение:
- `"partyIds"` - ищет точную строку "partyIds"
- `\s*` - ноль или более пробельных символов
- `:` - двоеточие
- `\s*` - снова пробелы
- `\[` - открывающая квадратная скобка
- `([^\]]+)` - **захватывающая группа** с содержимым (все символы кроме `]`)
- `\]` - закрывающая квадратная скобка

### Альтернативные regex:

#### 1. Только для чисел:
```regex
"partyIds"\s*:\s*\[([0-9,\s]+)\]
```

#### 2. Строгий поиск только цифр:
```regex
"partyIds"\s*:\s*\[(\d+(?:,\s*\d+)*)\]
```

#### 3. Универсальный (строки и числа):
```regex
"partyIds"\s*:\s*\[([^"\]]+)\]
```

## Примеры использования в Java:

```java
// Основной метод
Pattern pattern = Pattern.compile("\"partyIds\"\\s*:\\s*\\[([^\\]]+)\\]");
Matcher matcher = pattern.matcher(content);

if (matcher.find()) {
    String idsString = matcher.group(1); // Получаем содержимое между []
    String[] ids = idsString.split(",");
    // Обработка каждого ID
}
```

## Обработка результатов:

### Для чисел без кавычек:
```java
String cleanId = id.trim(); // Убираем только пробелы
int number = Integer.parseInt(cleanId); // Конвертируем в число
```

### Для строк в кавычках:
```java
String cleanId = id.trim().replaceAll("^\"|\"$", ""); // Убираем кавычки
```

### Универсальная обработка:
```java
String cleanId = id.trim().replaceAll("^\"|\"$", ""); // Убираем кавычки если есть
```

## Тестовые случаи:

✅ `"partyIds":[111,111,222,33333]` - числа без кавычек
✅ `"partyIds":["111","222","333"]` - строки в кавычках  
✅ `"partyIds": [ 111, 222, 333 ]` - с пробелами
✅ `"partyIds":[111,222,333]` - без пробелов

## Результат:
- Найдено: `[111, 111, 222, 33333]`
- Количество: **4 partyIds**
