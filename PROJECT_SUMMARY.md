## 🏗️ Архитектура приложения

### Основные компоненты

1. **MessageSenderService** - основной сервис для отправки сообщений
   - Асинхронная отправка через CompletableFuture
   - Retry механизм с экспоненциальной задержкой
   - Проверка доступности каналов перед отправкой

2. **ChannelMonitorService** - мониторинг каналов
   - Периодическая проверка доступности каналов
   - Отслеживание количества активных каналов
   - Предотвращение отправки при недоступности каналов

3. **MessageController** - REST API
   - Endpoints для отправки сообщений
   - Мониторинг статуса каналов
   - Тестовые endpoints

4. **RabbitMQConfig** - конфигурация RabbitMQ
   - Настройка очередей и exchange
   - Publisher confirms и returns
   - JSON сериализация

### Модели данных

- **Message** - основная модель сообщения
- **MessageBatch** - пакет сообщений для отправки
- **ChannelStatus** - статус каналов в брокере

### Основные настройки
```yaml

  rabbitmq:
    host: localhost
    port: 5672
    username: guest
    password: guest

  channel:
    max-available: 10
    check-interval: 5000
  queue:
    name: message.queue
  exchange:
    name: message.exchange
```
